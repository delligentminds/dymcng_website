DYMCnG Static HTML Website

Files included:
- index.html
- images/dymcng-logo.jpg
- images/yazdi-mehta-founder.jpg
- images/hero-students.svg
- images/parent-session.svg
- images/student-guidance.svg
- images/workshop.svg

Recommended real photos to replace placeholder SVG files:
1. images/hero-students.svg -> replace with hero-students.jpg
   Professional photo of Indian/international students studying or receiving guidance.
2. images/parent-session.svg -> replace with parent-session.jpg
   Parent-student discussion or counselling meeting.
3. images/student-guidance.svg -> replace with student-guidance.jpg
   Student and counsellor/mentor guidance session.
4. images/workshop.svg -> replace with workshop.jpg
   School classroom workshop or presentation photo.

If you replace SVGs with JPGs, update the image filenames inside index.html, or keep the same names and use SVG placeholders.

To publish on Vercel:
1. Upload this folder to GitHub.
2. In Vercel: Add New > Project > Import your GitHub repo.
3. Vercel will detect it as a static site. No build command is needed.
4. Deploy.
5. Add dymcng.com and www.dymcng.com under Project > Settings > Domains.

Contact form note:
The form currently uses https://formspree.io/f/YOUR_FORM_ID.
Create a Formspree account, create a form, and replace YOUR_FORM_ID in index.html.
Until then, the WhatsApp buttons work.
